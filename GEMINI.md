# Gemini Instructions for Study Flow

Always read:
- PROJECT_CONTEXT.md
- TODO.md

before making changes.

# Development Philosophy

This app is designed for stressed students preparing for exams.

The UI should feel:
- calm
- minimal
- responsive
- emotionally clear
- mobile-first

Avoid:
- clutter
- feature bloat
- unnecessary dependencies
- excessive animations
- rewriting working components

# Coding Rules

- Use React best practices
- Prefer Tailwind utility classes
- Keep components modular
- Avoid inline styles
- Reuse existing styles when possible
- Preserve existing functionality
- Make minimal targeted edits

# Responsiveness Standards

Mobile-first design is mandatory.

Ensure:
- no horizontal scrolling
- proper spacing on small screens
- responsive typography
- tappable buttons
- proper navbar collapse
- cards stack correctly
- layouts adapt smoothly

# Workflow Rules

Before editing:
1. Analyze relevant files
2. Explain planned changes briefly
3. Identify potential risks
4. Then apply minimal fixes

Do NOT:
- refactor unrelated files
- rename files unnecessarily
- install packages unless requested
- rewrite entire pages for small fixes

# Preferred Development Order

Priority:
1. responsiveness
2. UI cleanup
3. UX polish
4. performance
5. new features

# Design Direction

The app should feel:
- focused
- smooth
- modern
- lightweight
- calming during exam stress

Design inspiration:
- Notion
- Headspace
- Calm
- modern student productivity apps
