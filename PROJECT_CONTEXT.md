# Study Flow

A modern study organization app for students during stressful exam periods.

Core philosophy:
- calm UI
- minimal friction
- mobile-first
- fast interactions
- emotional clarity

Target users:
- high school students
- college students
- medical students
- exam preparation students

Core features:
- task organization
- study sessions
- focus timer
- progress tracking
- exam countdowns
- motivational/stress-reducing UX

Tech stack:
- React
- Tailwind
- Vite

Current priority:
1. responsiveness
2. UI cleanup
3. remove clutter
4. improve mobile UX
5. optimize landing page

Important:
Avoid feature bloat.
